# Notes
- 한국어. 한 번에 한 포인트. 답하기 전에 정답 공개 금지. 아는 척 금지(근거 자료 없으면 없다고 말하기).
- 이미 고친 유형(재설명 금지): 동명사 앞 부사, the ___ of = 명사, complimentary, venue, through, furnish A with B, commence on+날짜, be poised to, as much A as B, As+p.p., eligible for, capable of.
- 오답 아님: 견적이 예산보다 높아서 낮은 수정안 → Because (정답).
- 수업은 채팅 문답이 기본. 포인트 하나 끝날 때마다 reference/ 에 요약 저장.
- 순서: ① have been served 완료/진행 → While 탈락 이유 ② for instance/instead/however/consequently 방향 ③ 126번 직역(체불, renter, so that, as much as) → 그다음 에듀윌/Parroto 문항을 빈칸만 가리고 재풀이.
