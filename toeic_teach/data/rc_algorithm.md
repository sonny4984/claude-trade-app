# RC 풀이 알고리즘 (11/12 동하가 공유한 강의 슬라이드 8장, 빠짐없이 정리)

앞으로 모든 RC 해설·채점·변형문제는 이 알고리즘의 단계 이름으로 설명한다.
오답 해설은 항상 "알고리즘의 어느 단계에서 어긋났는가"를 먼저 말한다.

---

## 1. Part 5: 선지 생김새로 유형부터 (해석 없이 95%)
> Part 5는 해석이 아닌 '어울림'을 보는 파트, 95%는 해석 없이 풀린다.
> 문장을 보기 전 반드시 **선지의 생김새**에 따른 세 가지 문제 유형을 먼저 판단한다.

### A. 비슷하게 생겼는데 꼬다리만 다르면 → **문법 문제**
1. 빈칸 앞/뒤 방향 모두에서 다음 중 **빈칸과 가장 가까이 있는 것**을 찾는다
   1) 동사 2) 전치사 3) 접속사 4) to부정사 5) ing + 목적어 6) ed + 전치사구
2. 그 앞을 **슬래시로 끊고 두 슬래시 사이만 본다** & 수식어의 순서 확인 (**한정사 + 형용사 + 명사**)
3. Tip. 동사가 의심될 때: **접속사 + 1 = 동사** (접속사 개수 + 1 = 동사 개수)

### B. 전치사·접속사가 하나라도 있으면 → **전/접/부 문제**
1. **무조건 전/접이 1순위**, 나머지는 거른다. 특히
   1) **접속부사**(두 문장 필요) → Part 5에서 정답 불가
   2) **쓰레기부사**(up, off, out) → 전치사로 혼동 유발 多
2. 남은 선지의 품사가
   - **전치사 통일** → 전치사 **용법** 따지기 (없으면 해석)
   - **전/접 혼합** → **빈칸 뒤 명사구 → 전치사 / 빈칸 뒤 문장 → 접속사** (해석 X, best)
   - **접속사 통일** → **해석 필요** (앞뒤 문장 맥락 파악)

### C. 다 다르게 생겼는데 품사는 같으면 → **어휘 문제**
1) **동사** 어휘: **목적어(명사)** 확인 (자동사 주의)
2) **형용사** 어휘: **수식받는 명사** 확인
3) **명사** 어휘: **수식어(주로 형용사) & 동사** 확인
4) **부사** 어휘(고난도): **특징 있는 부사** 먼저 확인
→ 안 되는 경우만 해석

## 2. Part 6: 문법(P5) + 해석(P7) 둘 다 필요
> 우선은 **읽어보겠다는 태도** + **문법적으로 빨리 풀 수 있는 건 받아먹겠다는 태도**

### A. 파트5 유형
- **문법 문제**: 선 문법(50%) 후 해석(50%)
  - Tip. Part 6 **동사자리 문법문제는 99% 시제**(해석)
- **전/접 문제**: Part 5와 동일. 전 + 명사구 / 접 + 문장. 전치사는 용법, 접속사는 해석
- **어휘 문제**: **99% 해석 필요**

### B. 접속부사
1. 선지의 품사가
   - **전/접/접부 혼재** → **접속부사 자리 `[. ____ ,]`** 맞는지 확인
     - 아니면 → 전/접 문제로
     - 맞으면 → 종류 따지기
   - **접속부사로 통일** → 종류 따지기
2. 종류: 1) **역접** 2) **인과** 3) **추가** 4) 기타
   - Tip. **90%는 역접, 인과, 추가**에서 나온다

### C. 문장삽입
1. 삽입할 문장에 아래 중 **하나라도** 있나?
   1) **대명사**
      - 인칭대명사 (He, She, They, It)
      - 지시형용사·지시대명사 (This, That, These, Those)
      - **정관사 The (2순위)**
   2) **특수부사 "~도"** (also, too, as well)
2. **있다** → 있는 선지가 **1순위 후보**. **앞 내용에서 '받아주는 말'**을 찾는다
3. **없다** → **문단 통일성**(1문단 1주제) 파악

> 튜터 메모: 1순위 후보는 '먼저 검토할 순서'다. 받아주는 말이 앞에 있는지, 내용이 지문과 모순되지 않는지까지 확인하고 확정한다 (예: ETS Vol.3 T1 134 C는 these days가 있지만 north lobby 내용이 지문과 모순 → 탈락).

## 3. Part 7 단일지문: 문제 요구사항이 명확한가?

### A. 불명확한 문제들
1) **"~에 관해 사실인 것은?"** 형태: **What is ____ed about ~?**
   - implied / mentioned / stated / suggested / concluded / true
2) **"이 글의 목적은? 쓴 이유는?"**
   - What is the **purpose** of this ~? / **Why** did ~ **wrote** this ~?

→ 문제에서 잡은 대상에 관한 사실이 한 개가 아니라 여러 개 등장하며, 그 중 무엇이 정답인지 알 수 없다
→ **해당 문단 전체를 읽고 각 선지 모두 진위판단 필요**

### B. 명확한 문제들 (그 외 전부)
- Ex.1) What is -ed about Mr. Ko? → **불명확**
- Ex.2) Who is Mr. Ko? → **명확** (하는 일, 직업)

→ **나머지 사실은 전부 무시하고 요구사항만 집중하며 읽는다.** 읽는 도중 **"나왔다"**를 느끼면 **읽기를 중지하고 선지로** 간다
→ Tip. **마지막 문제일 경우** 그 즉시 읽기를 중지하고, 남아 있는 지문 분량에서 **요구사항만 찾고 끝낸다**
→ **절대 (A) 맞나 아닌가, (B) 맞나 아닌가 각 선지의 진위여부를 판단하지 않는다.**
   **마음속에 주관식 정답을 먼저 내리고, 선지에서 "그게 어디 있는지"만 찾는다** (훨씬 빠름 & 오답에 휘둘리지 않음)

## 4. Part 7 단일지문 읽기 순서 (알고리즘)
**대전제: 99%의 문제는 지문의 위에서부터 문항번호 순서대로 풀린다.**
예외: **목적**(항상 첫 문제), **문장삽입**(항상 마지막 문제) → 언제 풀릴지 알 수 없음

1. 문제 수와 상관없이 **왼쪽 문제들만 잡는다** (선지는 잡지 말 것)
   - 예외로 **문장삽입은 미리 잡고 만날 때마다 시도**한다 (문제는 항상 같으니 잡지 말 것)
   - Tip. **문단 구분이 안 되어 있으면 문장삽입 빈칸 위치를 임시로 문단 구별 위치**로 볼 수 있다
2. **문단 개수를 파악**한다. **한 문단당 한 문제씩 목발보행**을 준비한다
   - 예외로 **목록은 아무리 커도 한 문단**으로 친다
   - 목록은 대부분 쓸모없는 내용이니 줄줄 읽지 말고 **눈알굴리기**한다
   - Tip. **동의어 문제의 단어 위치**는 그 직전·직후 문제가 풀리는 **타점**을 잡는 데 큰 도움이 된다
3. **첫 문단을 읽고 반드시 바로 첫 문제를 시도한다. 절대 더 읽지 않는다.**
4. **풀리면?** 더 읽지 말고 다음 문제까지 풀리나 확인한다
   **안 풀리면?** 딱 한 덩어리만 더 읽고 온다
   → 마지막 문제가 풀릴 때까지 반복한다
5. 예외로 **목적은 안 풀리면 마지막 번호로 미룬다** (정답근거가 글 하단 혹은 글 전체인 경우 많음)

## 5. 정답은 숫자정보와 고유명사에서 나온다
- 지문 내 등장 시 중요도: **숫자정보 >>> 고유명사 >>>>>> 기타**
- 숫자정보나 고유명사가 **여러 개 연달아 등장**할 경우 홀로 등장할 때보다 훨씬 더 중요하다
- 적으면 2개, 많으면 6개까지 연달아 등장하며, **4개에 근접할수록 출제 확률이 기하급수적으로 상승**한다 (**지문 속 선지의 등장**)

### 눈치가 있으면...
> 그래서 Mr. Kim은 마트에서 바나나, 오렌지, 키위, 그리고 그의 여자친구를 위해 특별히 준비한 슈퍼울트라킹왕짱 딸기를 구매했다.
- 지문 속 선지의 등장: 4개 (바나나, 오렌지, 키위, 딸기)
- 그중 정답으로 출제될 것은 당연히... **특별한 설명이 붙은 것(딸기)**

## 6. Part 7 다중지문 (이중·삼중)
**대전제: 문제의 정답근거는 지문 전체에 걸쳐 균일하게 분포한다.**
**정답이 출제되지 않은 빈 공간은 반드시 다시 채우러 온다** (연계 출제 원리)

1. **첫 번째 지문까지는 오직 단일지문 알고리즘만** 따른다
   (단, **문제를 잡을 때 몇 번째 지문에 해당하는지도 잡는다**)
2. **두 번째 지문부터는 내려가기 전** 반드시 **그 전 지문에서 쓰이지 않은 빈 공간(피자 꼬투리)**을 찾는다
   - 발견 확률: **지문 하단 > 상단 > 중간**
   - Tip. 첫 번째 지문이 문단 구분 없는 글이어도 반드시 보이지 않는 피자 꼬투리를 찾는다 (**발골작업**)
3. **피자 꼬투리는 99% 연계**되므로 반드시 내용을 확인하고 내려간다
   - Tip. 시간이 없거나 꼬투리가 너무 크면 **숫자정보가 포함된 문장만 확인**하고, 그마저 힘들면 **곧 출제된다는 표시만** 하고 내려간다
4. 다음 지문으로 내려간 후로는 **당장의 문제와 상관없어도 피자꼬투리 정보의 재출현에 촉각**을 곤두세우고 읽는다
   - **"나왔다"**를 느끼면 즉시 읽기를 중지하고 문제풀이를 시도한다
- Tip. 문제는 n문단인데 **선지가 n+1, n-1문단의 내용**을 가리키고 있다면 잡을 때부터 연계문제임을 눈치채야 한다 (**강제연계**)
- Tip. 연계문제 개수는 **이중: 1개 / 삼중: 2개**. **3번까지 풀고 연계문제 푼 개수를 확인**하면 남은 문제의 연계 여부를 미리 알 수 있다

## 7. 동하 실제 오답 → 알고리즘 어긋난 단계 (ETS Vol.3 Test 1 등)

|---|---|---|---|
| P5 101 regional | 꼬다리만 다름 → 문법 | 빈칸 뒤 명사 goods → 한정사+**형용사**+명사 | 명사 region |
| P5 119 consistently | 꼬다리 → 문법 | 빈칸 뒤 ed(applied) → 그 앞 = 부사 | 형용사 |
| P5 125 substitutions | 꼬다리 → 문법 | 빈칸 앞 동사 make → 목적어 = 명사 | p.p. |
| P5 114 for | 전치사 통일 → 용법 | the past three years + 현재완료 → for | under |
| P5 102/118/122 | 품사 같음 → 어휘 | 명사 어휘: 수식어·동사(surrounding areas / doubled in) 확인, 형용사 어휘: feel ___ about | 해석으로 고름 |
| P6 138 superb | 형용사 어휘 | 수식어 순서 확인: **a** + 형용사 → 최상급 best 탈락 | best |
| P6 134 | 문장삽입 | 대명사 선지(C these, B·D the) 1순위 → 받아주는 말 + 모순 확인 | C (모순 놓침) |

| P7 161 | **불명확** (suggested) | 문단 전체 + 선지 진위판단 → rain or shine + tenting | C |

| P7 164 | 문장삽입 | they(대명사) → 받아주는 말 photographs → [1] | [4] |

| P7 187/190/193 | 다중지문 연계 | 피자 꼬투리(공지의 Branding Strategies, 표 가격 숫자, 기사의 permit on hold) → 재출현 시 연계 | 연계 못 함 |

## 8. 과외 선생님 팁 (11/13 수업, 동하 메모 그대로)
1. **소거법 활용**: 정답을 바로 찾기보다 확실히 틀린 선지부터 지운다.
2. **푸는 순서**: **P5 → 이중·삼중지문(176-200) → P6 → P7 단일지문(147-175)**
   - 머리가 맑을 때 제일 집중력이 필요한 다중지문을 먼저 푼다. (동하는 지친 상태에서 176-185를 10개 중 6개 틀린 적 있음)
   - 주의: 순서를 바꾸면 **OMR 칸이 밀리기 쉽다** → 파트 하나 끝날 때마다 바로 마킹하고 번호 확인.
3. **모르는 단어 vs 아는 단어**: 끝까지 판단이 안 되면 **아는 단어를 고른다** (마지막 찍기 기준).
4. **명사의 범위 확인**: 선지가 지문보다 범위를 넓히거나 좁히지 않았는지 본다. (예: 램프만 환불 ↔ 주문 전체 취소, 책 한 권 ↔ 책들)
5. **문제에 명사가 2개 나오면 첫 번째 명사를 따른다**: A of B / A in B 에서 핵심은 A (수일치, 질문의 대상).
