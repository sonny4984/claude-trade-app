## 11/6 측정 결과 반영 (data/analysis/p7_measured_comparison.md)
- P7 길이는 실제가 더 짧다(단일 67~157단어). 길이를 늘리는 대신 선지 설계를 바꾼다.
- 오답이 지문 단어를 재사용하는 비율을 실제 수준(문항의 1/3)으로 낮춘다. 정답은 지문 표현을 따른다.
- 지문의 40~60%는 문제와 무관한 정보. 정답 위치는 NATURAL_KEY로 불균등.
