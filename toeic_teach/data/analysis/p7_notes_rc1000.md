# 두 책 20회 Part 7 종합 전략 (기출5 + 1000 Vol.4)

## A. 질문 유형별 정답 찾는 위치
| 유형 | 회당 | 근거 위치 | 정답 형태 |
|---|---|---|---|
| 목적/주제 | 6-8 | 첫 1-2문장, 이메일 Subject | 상위어로 요약 (refund 요청 → "To request a change") |
| 세부(According to ~, What will ~) | 12-15 | 질문의 고유명사·날짜·숫자를 지문에서 스캔 | **반드시 패러프레이즈** (luncheon→meal, licensed opticians→certified professional) |
| 추론(suggested/most likely) | 8-10 | 한 문장 + 상식 1단계 | "new staff start Oct 16" → hiring / "near bankruptcy" → once struggling |
| 신원(Who is ~) | 2-3 | 이름 바로 옆 직책·소속 | 함정: 장소(reception desk), 다른 사람 직책, **책 속 등장인물** |
| NOT | 2-3 | 나열 부분(불릿, 쉼표 리스트) | 비슷하지만 조건이 다른 것(할인≠무료, 3일=다른 사람 숫자) |
| 동의어 | 3-5 | 해당 줄 문맥 | 문맥상 의미 (address concerns→respond to, handle weight→support, temper→moderate) |
| 의도(" ") | 2 | 인용문 **바로 앞 메시지** | 앞 메시지가 질문이면 그 답, 요청이면 수락/거절 |
| 삽입 [1]-[4] | 2-3 | 문장 속 지시어(this, these, it, also, however) | 지시어가 가리킬 명사가 바로 앞에 있는 자리 |
| 연계(이중/삼중) | 6-8 | 두 지문을 잇는 "공통 고리" | 아래 B 참조 |

## B. 연계 문제 고리 유형 (20회 실제 출현)
1. **표의 한 행** ↔ 다른 지문 조건: 인원 35명 → 45석 방 / 수량 10 → printer paper / 가격 상한 $175 → 호텔 제외
2. **날짜 경계**: 마감 Aug 5 vs 편지 Aug 6 → 마감 놓침 / 8월 프로모션 + 8월 31일 방문 → 할인 받음 / 24시간 전 규정 + 당일 아침 전화 → 수수료
3. **직책·역할 고리**: "모든 branch manager 필수 참석" + 기사 속 branch manager → 참석자 / head chef came out + head chef 이름
4. **집합 조건 → 개인**: "참가자 전원 10년 이상" → 응답자는 오래 근무 / "Members get 10%" + 영수증 Less 10% → 회원
5. **장소 조건 교집합**: 3층 + 카페테리아 옆 + 음식 허용 → Smith Room
6. **변경 사항**: 일정 이동(8 P.M. 공연이 다음날로 → 원래 시간에 다른 밴드) / 1지망 vs 실제 진행 활동
7. **계산**: as many A as B / following month / 원래 견적 vs 새 견적

## C. 함정 패턴 (오답 선지 설계)
- 지문 단어 그대로 재사용 + 주체/시점만 바꿈 (CTO는 남음 ↔ 이동, 과거 직업 ↔ 현재)
- 숫자 다른 행 끌어오기 (views 223,648 ↔ individuals 87,122 / 30 years ↔ anniversary)
- 그럴듯한 상식 (사진이 오래돼서 ✗ → 해상도 낮아서 ○)
- 변하지 않는 것을 변하는 것처럼 (processing time remain three days)

## D. 지문 그래픽 레퍼토리 (내 엔진 반영 대상)

## E. 동하용 풀이 루틴 (P7 55분)
1. 질문 먼저 훑기 → 고유명사·숫자·NOT/most likely 표시 (10초)
2. 목적 문제는 첫 문단, 세부는 키워드 스캔 → 선지는 **패러프레이즈된 것** 고르기 (지문과 똑같은 단어 선지는 의심)
3. 의도 문제: 인용문 앞 메시지 1개만 다시 읽기
4. 삽입: 제시문의 this/these/also/however 먼저 찾고 앞 문장에 짝 있는 위치
5. 이중/삼중: 두 번째 지문 문제부터 "다른 지문의 무엇과 이어지나?" (표 행·날짜·직책·조건) 먼저 묻기
6. 시간 배분: 단일 29문항 25분 / 이중 10문항 10분 / 삼중 15문항 18분 / 검토 2분
