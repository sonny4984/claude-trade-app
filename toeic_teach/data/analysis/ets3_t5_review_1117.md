# ETS Vol.3 Test 5 RC 오답 리뷰 (11/17) — 내일 재구성 문제 출제용

결과: P5 25 / P6 13 / P7 단일 24 / 다중 18 → 80/100. 별도로 Test 3 P5 21/30 (9개 오답, 동하가 꺼낼 때까지 보류).

## 오답과 원인
| 문항 | 동하 답 → 정답 | 원인 |
|---|---|---|
| P6 139 | Those → Other | one kind ↔ other 꼬투리, those 넣고 모순 확인 안 함 |
| P6 141 | (influence 지움) → influence | this = 앞 문장 주어(consideration)로 안 바꿈 |
| P6 146 | celebrates → celebration | A, B, and C 명사 나열 and를 절 접속사로 셈 |
| 154 | transcripts → résumé | 자격(mandatory) 줄 ≠ 지원 방법(To be considered) / certificate≠transcript |
| 166 | public documents → interviewing employees of a firm | these sources = two architects |
| 167 | manufacturing jobs → construction of new building | soon-to-be constructed / 사무실≠제조업 |
| 169 | Russia → Brazil | featured at fashion show = seen by audience / similar trend = 매출 증가 |
| 178 | marketing consultant → had a coffee club before | reinstate·bring back·brought back / suggest 문제는 위치 순서 안 지킴 |
| 180 | pay off → trade in | redeem points for discounts, 문장에 넣어 안 봄 |
| 183 | met at university → both in HR | our department(채용공고 낸 부서) + director of Human Resources |
| 185 | communication → experience | 5 years vs three years ago (숫자 연계), NOT은 확실한 ✗ 우선 |
| 197 | business trips for company → used Adamek's services | Thanks … as always |
| 199 | changed airlines → visited a restaurant | advice = Peruvian lunch place ↔ 영수증 Peru Dreaming Café |

## 공통 원인 3개 (재구성 문제 타깃)
1. 가리키는 말(this/those/these/our department/similar trend/advice)을 진짜 대상으로 바꾸지 않음 — 7문항
2. 주제·단어만 비슷한 선지 (manufacturing, consultant, transcripts, university, often) — 6문항
3. 이중·삼중 숫자·장소·날짜 연계 (5 vs 3 years, Peru café, HR) — 4문항
