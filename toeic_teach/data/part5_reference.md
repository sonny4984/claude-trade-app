# TOEIC Part 5 개인 정리 (동하 전용)

목표 950, 시험 10/11. 이 문서는 앱의 "규칙 화면"과 해설 문구의 원본이다.
원칙: Part 5는 "자연스러움"이 아니라 "호응"으로 푼다. 선택지 보기 전에 빈칸 앞뒤 한 단어씩 먼저 본다.

---

## 0. 풀이 순서 (3초 루틴)

1. 빈칸 바로 앞 단어, 바로 뒤 단어에 동그라미 (품사·수·숫자·전치사·주어 유무)
2. 선택지 품사가 같은 어근이면 -> 품사 문제. 해석 금지
3. 선택지 뜻이 다 다르면 -> 어휘 문제. 연어(같이 쓰는 단어)로 거른다
4. 선택지가 전치사/접속사/접속부사 섞여 있으면 -> 뒤에 명사(구)인지 절(S+V)인지 먼저 본다
5. 마지막에 해석으로 확인

## 1. 품사 자리 규칙

| 빈칸 위치 | 들어갈 품사 | 예 |
|---|---|---|
| a/the/소유격 + ___ + 명사 | 형용사 | a considerable increase |
| a/the + ___ + of | 명사 | the addition of |
| be동사, remain, seem, become, stay 뒤 | 형용사 | remain engaged / are profitable |
| 일반동사 뒤 (완전한 문장 끝) | 부사 | proceed cautiously |
| 형용사/분사/비교급 앞 | 부사 | considerably different |
| 전치사 + ___ + 목적어 | V-ing | After reviewing our policies |
| 주어 자리 | 명사 | Advancements in cloud computing |
| to + ___ | 동사원형 | decided to proceed |

주의: be + p.p.(수동) / be + V-ing(진행) 자리는 형용사보다 분사가 먼저 떠오를 때가 있으니 뒤에 목적어가 있는지 본다. 목적어 있으면 능동(-ing), 없으면 수동(-ed).

## 2. 빈칸 옆 단서 (오답 원인 1순위)

| 단서 | 정답 방향 | 예 |
|---|---|---|
| 빈칸 뒤 숫자(4,000 / 11 million) | almost, nearly, about, approximately, roughly, over, more than (quite·always·closely 불가) | Almost 4,000 systems |
| 주어가 3인칭 단수 + 조동사 없음 | 동사에 s 또는 과거형 | Maria Stanley revealed |
| 주어가 복수 + 조동사 없음 | 원형 | groups may submit |
| who 뒤 동사가 단수(is, has) | anyone who (those who는 복수 동사) | Anyone who is unable |
| 빈칸 뒤에 주어 없이 p.p.만 | in case 불가 (in case는 S+V 필요) | posted online rather than mailed |
| 빈칸 앞에 front / back | cover | front cover of the magazine |
| 빈칸 뒤 on + 웹사이트/앱 | available | available on the Web site |
| 앞에 composer/author, 뒤에 a new work | 오케스트라/밴드는 perform | The orchestra will perform |

## 3. 시간·장소 전치사

- at = 점 (at 7:00, at noon, at night, at the end of, at the beginning of)
- on = 날짜·요일 (on Monday, on July 15, on Monday morning)
- in = 큰 기간 (in 2026, in September, in the morning, in two weeks = 2주 후에)
- during = 특정 사건·기간 (during the meeting)
- throughout = 처음부터 끝까지 내내
- by = ~까지 (완료) / until = ~까지 (계속)
- around = ~쯤 (end around 4 P.M.), until은 end와 불가
- opposite + 명사 = 맞은편 / across from + 명사 (from 필수)
- at = 지점·장소 / in = 내부·범위

## 4. 전치사 vs 접속사 vs 접속부사

뒤가 명사(구)면 전치사, 절(S+V)이면 접속사, 콤마 앞에 단독이면 접속부사.

| 의미 | 전치사 (+명사) | 접속사 (+절) | 접속부사 (단독, 콤마) |
|---|---|---|---|
| ~에도 불구하고 | despite, in spite of | although, though, even though | however, nevertheless |
| ~때문에 | because of, due to, owing to | because, since, as | therefore, as a result, consequently |
| ~동안 | during, throughout | while | meanwhile |
| ~후에 | following, after | after | afterward, then |
| ~에 더해 | in addition to, besides | not only ... but also | in addition, moreover, furthermore |
| ~대신에 | instead of, rather than | | instead |
| ~전에 | prior to, before | before | |
| ~와 관계없이 | regardless of | | |
| ~하는 경우에 대비해 | | in case + S+V | |
| 조건 | | if, unless, provided that, as long as | otherwise |

접속부사 A그룹(콤마 앞 단독 가능): However, Therefore, Thus, Hence, As a result, Consequently, Accordingly, In addition, Moreover, Furthermore, Also, In fact, Indeed, For example, For instance, Instead, Otherwise, Meanwhile, Before long, Afterward, Then, After all, Nevertheless, Nonetheless, On the contrary, In contrast, There, Similarly, Likewise, Overall, In short
B그룹(보이면 즉시 탈락): Now that, Because, Since, As, Although, Though, Even though, While, When, After, Before, If, Unless, So that, Whereas

혼동 짝:
- Otherwise: 앞에 조건·지시가 있어야 함 / Instead: 앞을 취소
- After all: 뒤가 앞의 근거 / Before long: 머지않아 (시간 경과)
- also가 문장에 있으면 Rather than 탈락, In addition to가 답
- in case는 뒤에 S+V 필수, rather than은 병렬 구조에서 사용

## 5. 준동사

- following + 명사 = ~ 후에 / A is followed by B = A 뒤에 B
- recommend + V-ing, suggest + V-ing, consider + V-ing, avoid + V-ing, finish + V-ing
- praise A for V-ing, thank A for V-ing, be committed to V-ing, look forward to V-ing
- 분사 판별: 꾸밈받는 명사가 감정을 일으키면 -ing, 감정을 느끼거나 당하면 -ed
  - frustrating change / frustrated staff, engaging presentation / engaged audience
- 분사구문: 동사 이미 있음 + 접속사 없음 + 뒤에 목적어 있음 -> -ing (call into the meeting using the network)
- considering = ~을 고려하면 / considered = 고려된, 여겨지는
- neglect to V (to부정사 가능) / reject + 명사 (to부정사 불가)
- remain + 형용사 (remain engaged)

## 6. that절 (제안·요구)

suggest / recommend / request / require / insist / demand / propose / ask + that + S + 동사원형
수동이면 be + p.p. (주절이 과거여도 was 아님)

## 7. 관계사·대명사

- who = 사람 주어 (뒤에 동사) / whom = 사람 목적어 (뒤에 S+V, 또는 전치사·of 뒤)
- which = 사물, 앞 문장 전체를 받기도 함
- neither/both/some/all/many/most/one + of whom
- Those who + 복수 동사 / Anyone who + 단수 동사
- 비교 대상 되받기: 단수 that, 복수 those (as delicious as those we enjoyed)

## 8. 명사절

- how + S + V = 어떻게 ~하는지 (decide how)
- where + S + V = 어디에서
- whether + to V = ~할지 말지 (whether만 to V와 결합)
- what + 불완전한 절 = ~하는 것

## 9. 고정 전치사 덩어리

comply with / compatible with / familiar with / qualified for / eligible for / responsible for / regardless of / subject to / adhere to / account for / capable of / available on(for) / in addition to / according to / be committed to / on a ~ basis

## 10. 혼동 어휘 짝

| A | B | 구분 |
|---|---|---|
| cover | coverage | 표지(front cover) / 보도·보장 범위 |
| capable (of) | available (on/for) | 능력 있는 / 이용 가능한 |
| perform | make, create | 연주·공연하다 / 만들다 |
| neglect | reject | ~하지 않다(to V) / 거절하다(+명사) |
| widely | closely | widely available / closely related, monitor |
| permanent | previous | 상설 / 이전의 (limited-time과 대조) |
| addition | substitution | addition of A to B / substitution of A for B |
| often | well | 흔히 / 잘 (형용사 challenging 수식 불가) |
| almost, nearly | quite | 숫자 앞 가능 / 숫자 앞 불가, quite는 "꽤" |
| lively | plentiful | 활기찬(행사) / 풍부한(양) |
| diligently | completely | work diligently / finish completely |
| be on track | expedite | 예정대로 진행 중 / 신속 처리하다 |
| rectify | discrepancy | 바로잡다 / 불일치 |
| -ee | -er/-or/-ant | 받는 사람(employee, attendee) / 하는 사람(employer, instructor, applicant) |

## 11. 시험 직전 한 줄

- 빈칸 옆 두 단어부터. 숫자 -> almost류, who 뒤 단수 -> anyone, 주어 단수 -> 동사에 s
- that절 -> 동사원형 / be p.p.
- 뒤가 절이면 접속사, 명사면 전치사, 콤마 단독이면 접속부사
- 어휘는 뜻이 아니라 짝으로: widely available, front cover, neglect to V, perform a work
