# TOEIC Part 5 Resources

## Knowledge

- [Merriam-Webster: once (conjunction)](https://www.merriam-webster.com/dictionary/once)
  conj. "at the moment when / as soon as", 예: "Once she spoke, I recognized her." Use for: once 의미, 시간 순서.
- [Merriam-Webster: so long as](https://www.merriam-webster.com/dictionary/so long as)
  시간("~하는 동안") 또는 조건("~이기만 하면") 접속사. Use for: so long as 구별.
- [Macmillan Writer's Help: Conjunctive adverbs](https://digfir-published.macmillanusa.com/writershelp2e/writershelp2e_ch16_35.html)
  접속부사의 기능 분류(대조, 첨가, 결과, 예시 등)와 구두점. Use for: however / moreover / consequently / for instance 방향.
- [ETS: TOEIC Listening & Reading content and format](https://origin-www.ets.org/toeic/test-takers/listening-reading/about/content-format)
  공식 시험 구성. Use for: 시험 형식.

## Wisdom (Communities)

- 요청 없음. 시험이 가까워 우선순위 낮음.

## Gaps

- 현재완료(수동)가 once/when/after 절에서 "완료"를 나타내는 규칙을 직접 설명하는 1차 자료를 아직 못 찾음 (Cambridge 문법 페이지 접근 403). 확인 전까지는 once의 뜻과 문장 의미에서 따져서 가르치고, 자료로 확인된 규칙인 척 하지 않는다.
- "as much A as B" 구문의 1차 자료 미확보.
